# Third-party notices

Counterspell is distributed under the MIT License in `LICENSE`.

This file is a notice scaffold for dependencies and assets used by the
project. It does not claim that notices are complete until dependencies are
installed and their license metadata has been checked.

## Current dependencies

No runtime or frontend dependencies are included in this repository skeleton
yet. The dependency notices will be added here as packages are introduced and
verified.

## Future notices

Each entry should include the dependency name, version, copyright holder,
license, source URL, and any required notice text. Generated notices must not
replace the license text supplied by the dependency.
