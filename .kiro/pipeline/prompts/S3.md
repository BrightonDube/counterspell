# Stage S3: signature, schema and metadata

## Inputs
- The S2 statement and the S0 brief.

## Do
Write `packs/<slug>/meta.toml` (public, samples only):

- `origin = "original"` and `licence = "MIT"`.
- `pack_version = 1` for a new pack.
- One to five concept tags, each present in `packs/catalogue.toml`.
- The function name and typed signature. Supported types: `int`, `str`, `list[int]`, `list[list[int]]`.
- The input schema that matches the statement.
- `[[samples]]` only. Do not add a `[generator]` table here. The generator goes to the private tree in S5.
- `complexity_note` of 240 characters or fewer. This stage does not set `difficulty`; S8 does.

Do not add `reference_complexity` or a `[bench]` table. Those belong to a later spec.

## Output
- `packs/<slug>/meta.toml` (public).

## Stop condition
`GRM-8` to `GRM-18` pass, `pack_version` is 1, and there is no `reference_complexity`.

## Rules
- The public `meta.toml` holds no hidden data.
