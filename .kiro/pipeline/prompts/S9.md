# Stage S9: static validation (assembled tree)

## Inputs
- The public tree `packs/<slug>/` and the private tree for the slug.

## Do
1. Assemble both trees, so that the validator sees one folder:

   ```
   scripts/pack-assemble.sh <slug> . <private-root>
   ```

2. Run the static validator on the assembled folder that the script reports:

   ```
   counterspell-grimoire validate --deny-warnings target/pack-assembly/<slug>
   ```

3. Record the codes and pointers from the report. Do not record file contents.

## Output
- The validator report (codes, pointers and counts only), in session notes.
- State `stage = "S9"`, and `status = "static_complete"` only after S10 and S11 have passed. Until then, keep the status `in_progress`.

## Stop condition
The validator exits with zero errors and zero warnings on the assembled tree (PIP-16).

## Rules
- Do not run any pack file with `python`, `python3`, `node` or a shell (PIP-38). The validator reads files only.
- If the private tree is missing, stop with `PIP-34`. Never continue on the public tree alone.
- Delete `target/pack-assembly/<slug>` after the stage run.
