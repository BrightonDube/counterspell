# Stage S2: statement and examples

## Inputs
- The S0 brief and the S1 record.

## Do
Write `packs/<slug>/problem.md`:

1. A title and a `## Task` section that names the function, its arguments and its return type.
2. A `## Constraints` section that matches `input_schema` exactly. Say "integer" wherever negative numbers are allowed.
3. A `## Examples` section. It must contain a call to the function with the result of sample 1, then two to four lines of explanation (STM-03).
4. Plain words. Short sentences. Define any term a non-native English reader may not know.

## Output
- `packs/<slug>/problem.md` (public).

## Stop condition
`GRM-19`, `GRM-20`, `STM-01` to `STM-03` pass.

## Checklist items this stage must answer
- `RV-clarity-1`: the call, arguments and return type are named in `## Task`.
- `RV-clarity-2`: the worked example matches sample 1.

## Rules
- Write only your own wording (PIP-3).
- Do not add a sample or a hidden value that is not in `meta.toml` and the private tree.
