# Catalogue Batch 16 Requirements

## Theme

Mathematics, geometry and bit manipulation: number properties, coordinate reasoning and compact binary state.

## Requirements

- Author 10 original packs: four easy, four medium and two hard.
- Supply complete Python, JavaScript, Java and C++ assets and define numeric bounds precisely.
- Cover zero, negatives where allowed, overflow boundaries and geometric degeneracy.
- Include original hints, tests, generators and known ghosts.
- Publish only when the whole batch passes review, sandbox and approval.
