# Catalogue Batch 17 Requirements

## Theme

Databases, SQL and data modelling: relational reasoning expressed through deterministic algorithmic pack interfaces.

## Requirements

- Author 10 original packs with four easy, four medium and two hard.
- Keep pack execution inside the existing sandbox protocol; do not add a database service to untrusted runs.
- Model joins, grouping, keys, transactions and query planning through bounded records and operations.
- Provide complete Python, JavaScript, Java and C++ assets, hints, references, tests and ghosts.
- Require full-batch originality, review, sandbox and approval gates before publication.
