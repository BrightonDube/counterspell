# Catalogue Batch 14 Requirements

## Theme

Two-dimensional dynamic programming: grids, paired sequences, partitions and multi-axis state.

## Requirements

- Author 10 original packs: four easy, four medium and two hard.
- Include complete assets for Python, JavaScript, Java and C++.
- Bound state sizes so references pass the production sandbox.
- Provide original hints, tests, generators and known ghosts.
- Require review, sandbox validation and approval for all packs before publication.
