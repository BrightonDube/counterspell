# Workspace Performance and Costume Design

## Readiness stages

1. **Shell:** stable problem, editor and control geometry.
2. **Editor:** Monaco core and selected language are interactive.
3. **Tools:** console, hints, results and Familiar initialise on demand.
4. **Atmosphere:** decorative art, video and non-essential motion load after interactivity or during idle time.

## Implementation direction

Use dynamic imports at route and feature boundaries, visibility-aware initialisation, explicit media dimensions, modern responsive sources and stable cacheable URLs. Avoid JavaScript animation loops where CSS transforms and opacity suffice. Guard every decorative selector so absent optional artwork does not produce console warnings.

## Testing

Use repeatable mobile Lighthouse profiles, production bundle analysis, browser performance marks, transfer totals and interaction smoke tests. Verify run, submit, console, hint and ghost paths whenever the production sandbox and an authenticated session are available.
