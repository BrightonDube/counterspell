# Catalogue Batch 19 Requirements

## Theme

Networking, distributed systems and security: routing, replication, consistency, validation and defensive protocol reasoning.

## Requirements

- Author 10 original packs with four easy, four medium and two hard.
- Keep all tasks defensive and educational; do not create exploit, credential theft or evasion exercises.
- Model networks and protocols as deterministic graphs, messages and logs.
- Include complete Python, JavaScript, Java and C++ assets, hints, references, tests and ghosts.
- Require originality, security review, pack review, sandbox validation and approval before publication.
