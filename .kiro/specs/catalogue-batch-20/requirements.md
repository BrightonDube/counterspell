# Catalogue Batch 20 Requirements

## Theme

AI, data processing and mixed capstones: vector operations, ranking, token streams, model evaluation and cross-domain synthesis.

## Requirements

- Author 10 original packs: four easy, four medium and two hard.
- Use deterministic algorithmic tasks; no pack depends on a remote model or nondeterministic service.
- Include complete Python, JavaScript, Java and C++ assets, hints, references, tests, generators and ghosts.
- Hard packs should combine at least two previously taught domains without becoming puzzle trivia.
- Publish only after the complete final batch passes originality, review, sandbox and approval gates.
