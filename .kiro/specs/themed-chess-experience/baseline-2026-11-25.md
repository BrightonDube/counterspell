# Chess experience — baseline (2026-11-25, pre-CH01)

Captured from `web/src/routes/break/{bot,puzzle}/+page.svelte` +
`cm-chessboard@<installed>` default theme + `pieces/standard.svg` (CC BY-SA
cburnett pieces).

## Geometry
- Route surface: `max-w-2xl` column; board div `class="break-board max-w-md"`
  → board capped at 448 px regardless of viewport; `aspect-ratio:1` reserved
  by `.break-board` in `app.css` (AQ07).
- `responsive: true` default — board fills its container on resize.
- No coordinates configured (default on, `borderType: none`).

## Logic (unchanged ground truth)
- `chess.js` drives position/moves; `enableMoveInput` validates against
  `game.moves()`.
- Bot: `bot.worker.js` → minimax in a Worker, random fallback, score saved on
  game end via `session.load()` + `saveScore({game:'chess_bot'})`.
- Puzzle: `fetchDaily` → `newPuzzle` → `tryMove` validation; solve →
  `saveScore({game:'chess_puzzle'})` session-gated.
- No `Markers` extension registered on either page — last move / legal
  targets are not visually marked today.

## Accessibility
- Board container: `role="img" aria-label="Chessboard"`; injected svg is set
  `aria-hidden="true"` post-mount (AQ fix).
- Status line is `<output aria-live="polite">`; verdict/status `<p role="status">`.
- No keyboard move input (library limitation — unchanged by this spec).

## Performance
- `standard.svg` sprite fetched once (~10 kB); board mounts after dynamic
  `import('cm-chessboard')` in `onMount` (keeps routes server-renderable).
- No atmosphere/decorative elements on either route.

## Palette
- Board uses the library `default` theme: `#ecdab9`/`#c5a076` squares,
  `#b5936d` coordinates — warm parchment tones, not Steel Night.
