# Catalogue Batch 06 Requirements

## Theme

Linked structures and pointer safety: traversal, reversal, merging, cycle reasoning and structural edits.

## Requirements

- Author 10 original packs: four easy, four medium and two hard.
- Supply complete Python, JavaScript, Java and C++ starters, references, hints and tests.
- Cover null heads, singleton structures, cycles, shared tails and mutation constraints where relevant.
- Keep prose, fixtures and solution design original.
- Publish only after every pack passes review, sandbox and approval.
