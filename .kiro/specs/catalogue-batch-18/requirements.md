# Catalogue Batch 18 Requirements

## Theme

Operating systems, concurrency and systems: scheduling, caches, memory, logs and interleavings.

## Requirements

- Author 10 original packs: four easy, four medium and two hard.
- Express systems behaviour as deterministic input and output, never real thread or process control.
- Provide complete Python, JavaScript, Java and C++ starters, references, hints, tests and known ghosts.
- Cover empty workloads, ties, starvation risks, wraparound and bounded resource limits.
- Publish only after the entire batch passes originality, review, sandbox validation and approval.
