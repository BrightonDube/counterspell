# Catalogue Batch 09 Requirements

## Theme

Heaps, priority queues and scheduling: top-k selection, merging, deadlines and event ordering.

## Requirements

- Author 10 original packs with a four easy, four medium and two hard split.
- Supply complete Python, JavaScript, Java and C++ assets.
- Cover ties, empty queues, stale events and large priorities.
- Include original statements, hints, references, tests and known ghosts.
- Publish only when all 10 packs pass review, sandbox validation and approval.
