# Catalogue Batch 13 Requirements

## Theme

One-dimensional dynamic programming: state transitions, subsequences, decoding and bounded optimisation.

## Requirements

- Author 10 original packs with four easy, four medium and two hard.
- Supply complete Python, JavaScript, Java and C++ starters and reference solutions.
- Make recurrence, base cases and complexity teachable through four hints.
- Include original visible and hidden cases, generators and ghosts.
- Publish only as a fully passing reviewed and sandbox-validated batch.
