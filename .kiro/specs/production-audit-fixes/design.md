# Production Audit Fixes Design

This spec is an audit-closure ledger, not a second implementation owner. Each finding maps to exactly one specialist child spec and one production acceptance probe.

## Ownership

- `production-foundations`: cache, TLS, CSP, 404s, resource files, public API caching and monitor semantics.
- `language-consistency`: language API, starters, editor and driver contract.
- `accessibility-seo-auth-quality`: metadata, headings, targets, landmarks, contrast, signed-out copy and request quality.
- `workspace-performance-costume`: workspace transfer, interaction readiness and media deferral.
- `lantern-recall-polish` and `themed-chess-experience`: agreed break-room polish and regressions.
- Catalogue batches: published breadth, difficulty, language and domain coverage.

The final audit repeats the original methodology where possible and explains any changed environment or measurement profile.
