# Production Audit Fixes Requirements

## Goal

Provide one evidence ledger for every verified public and authenticated audit finding so no issue is lost between specialist child specs.

## Requirements

- Record each verified finding, severity, original evidence, owning child spec and live acceptance probe.
- Include language mismatch, caching, TLS, CSP, catalogue coverage, workspace performance, 404s, SEO, resource files, console quality, accessibility, media transfer, API caching, auth UX, monitoring and URL handling.
- Include authenticated chess copy, dashboard landmark, onboarding contrast and chessboard accessible-name findings.
- Include the missing GSAP target warning, production source-map decision and manual contrast review for surfaces axe could not resolve.
- Mark a finding complete only after its owner is merged, deployed and verified at `https://counterspel.online`.
- Preserve local and production baselines so regressions are visible.
- Keep sandbox-dependent authenticated run, submit, ghost and IDE verification open until direct production evidence exists.
- Record human-gated infrastructure findings with an owner and exact next action rather than treating them as code-complete.
