# Catalogue Batch 04 Requirements

## Theme

Sliding windows and streaming statistics: fixed, variable and multi-constraint windows.

## Requirements

- Author 10 original packs with four easy, four medium and two hard.
- Require Python, JavaScript, Java and C++ starters and references before publication.
- Cover empty windows, impossible constraints, repeated values and large streams.
- Include original hints, visible and hidden tests, generators and known ghosts where useful.
- Publish only as one fully passing batch after sandbox validation and approval.
