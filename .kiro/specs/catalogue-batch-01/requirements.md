# Catalogue Batch 01 Requirements

## Theme

Arrays and hashing: frequency maps, membership, grouping, prefix summaries and index relationships.

## Requirements

- Author 10 original packs: four easy, four medium and two hard.
- Include Python, JavaScript, Java and C++ starters and references.
- Include four hints, visible and hidden cases, deterministic generators where useful and known ghosts where useful.
- Avoid copied names, prose, examples, tests or solution structure from NeetCode or other catalogues.
- Pass static validation, originality review, pack review, sandbox validation and Brighton approval before the batch is published.
