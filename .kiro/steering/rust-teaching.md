# Rust teaching

Brighton is new to Rust. After every Rust change, add a short **Rust lesson** of 3–5 lines in plain English. Explain ownership, borrowing, `Result`/`?`, async, or traits when they matter.

- Never use `unwrap()` or `expect()` outside tests.
- Prefer clear, simple code over clever generics.
- Return useful errors and preserve context at trust boundaries.
- Keep examples small enough for Brighton to review.
