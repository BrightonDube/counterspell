# The Diagonal Total

## Task
Call `diagonal_total(grid)` and return the integer sum of the cells whose row and column numbers are equal.

## Input
A grid of integers as a list of rows. Every row has the same length.

## Output
Return the diagonal sum as an integer. A grid with no rows or no columns has a sum of 0.

## Examples
`diagonal_total([[1, 2], [3, 4]])` returns `5`.
The first row contributes 1 and the second row contributes 4.

## Constraints
The grid has at most 6 rows and at most 6 columns. Each cell is from -9 to 9.
