# The Prime Ward

## Task
A ward holds every prime number up to its cap. Call `prime_ward(n)` and return how many primes sit at or below `n`.

## Input
`n` is a whole number from `0` to `200000`.

## Output
The count of primes `p` with `2 <= p <= n`.

## Examples
- `prime_ward(10)` returns `4` — `2, 3, 5, 7`.
- `prime_ward(2)` returns `1`.
- `prime_ward(1)` returns `0`.

## Constraints
- `0 <= n <= 200000`
