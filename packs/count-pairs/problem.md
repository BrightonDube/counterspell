# Count the Pairs

## Task
Call `count_pairs(values, target)` and return the number of pairs of positions `i < j` whose values add up to the target. Return an integer. Each pair of positions counts separately.

## Input
A list of integers and an integer target. An empty list has no pairs.

## Output
Return the number of matching pairs as an integer.

## Examples
`count_pairs([1, 2, 3, 2], 4)` returns `2`.
The first and third positions make one pair. The second and fourth positions make the other.

## Constraints
The list has at most 30 values, each from -50 to 50. The target is from -100 to 100.
