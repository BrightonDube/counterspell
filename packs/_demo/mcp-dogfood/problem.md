# Best Window Sum

## Task
Given a list of whole numbers and a window size k, find the largest total of any k values that sit next to each other in the list. If k is larger than the list, the answer is 0.

## Input
A list of whole numbers, then the window size k.

## Output
One whole number: the largest sum of any k neighbouring values, or 0 when k is larger than the list.

## Examples
The public examples are listed in the pack's samples.

## Constraints
The list has at most 30 values, each from -50 to 50. The window size k is from 1 to 30.
